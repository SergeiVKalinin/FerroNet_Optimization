# Direct waveform — FerroSim optimization

[FerroSim_Direct_Waveform_v4.ipynb](FerroSim_Direct_Waveform_v4.ipynb) evolves the **900 sampled electric-field values directly**, without Legendre/Fourier/spline coefficients, imposed amplitude limits, endpoint constraints, or crossover repair. It compares three pure genetic algorithms under the same physical evaluation budget and shared initialization: hard crossover (one-point or two-point), smooth blended crossover, and mutation-only evolution. The genetic mutations add Gaussian spikes, add field steps, or replace waveform segments; sharp transitions are allowed.

The notebook follows the **Legendre Try/v4** experiment and analysis sequence: configurable disorder maps, seeds and generations, physical reward convergence, waveform histories, reward–complexity Pareto fronts, complexity-retention statistics, paired comparisons, operator attribution, optional cross-disorder transfer, and numerical validation. The shared T1–T4 texture analysis independently reevaluates reward-improving waveforms and archives their polarization and curl configurations. **Curl remains the sole reward**, and no jump-count or jump-magnitude metrics are added. DKL calibration is explicitly marked inapplicable because no surrogate is trained.

Open the notebook in a fresh Anaconda/Jupyter Python 3.11 kernel with NumPy, pandas, SciPy, Matplotlib, Numba, and IPython/JupyterLab installed; change the first configuration cell and run all cells. The notebook embeds its required Python modules and saves physical observations, restartable local checkpoints, CSV summaries, texture NPZ files, and figures in a source/configuration-keyed runtime directory. Start with `N_DISORDERS=1`, `INITIAL_CONTROLS=2`, and `GENERATIONS=0` or `1`. See the [shared v4 guide](../FerroSim_v4_README.md). Full end-to-end numerical execution has not yet been independently verified.
